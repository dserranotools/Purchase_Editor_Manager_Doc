# PEM - Purchase Editor Manager - Documentation

---

## 🇬🇧 English

Comprehensive technical and business documentation for **PEM (Purchase Editor Manager)** — a Windows desktop application that acts as an intelligent intermediary between the **SO99+ demand planning system** and the client's **ERP**.   
PEM imports purchase proposals, applies business rules (netting, substitutions, centralization), and lets planners review and resolve issues before exporting optimized purchase and transfer orders to the ERP.

The documentation is available in **two formats**:

| Format | Folder | Description |
|---|---|---|
| 📄 **One-doc** | [`en/one-doc`](./en/one-doc/README_en_one-doc.md) | Single file (~50KB, 20 sections). Best for searching, PDF export, or sharing |
| 📚 **Multi-doc** | [`en/multi-doc`](./en/multi-doc/README_en_multi-doc.md) | 3 files by audience: Developers, Business Analysts, Planners |

Both formats contain **exactly the same information**.

## 🇪🇸 Español

Documentación técnica y de negocio completa de **PEM (Purchase Editor Manager)** — una aplicación de escritorio Windows que actúa como intermediario inteligente entre el sistema de planificación de demanda **SO99+** y el **ERP** del cliente.   
PEM importa propuestas de compra, aplica reglas de negocio (netificación, sustituciones, centralización) y permite al planificador revisar y resolver incidencias antes de exportar órdenes de compra y traspaso optimizadas al ERP.

La documentación está disponible en **dos formatos**:

| Formato | Carpeta | Descripción |
|---|---|---|
| 📄 **One-doc** | [`es/one-doc`](./es/one-doc/README_es_one-doc.md) | Un solo archivo (~50KB, 20 secciones). Ideal para buscar, exportar a PDF o compartir |
